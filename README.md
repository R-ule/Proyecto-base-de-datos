# UTM Desk - Backend NoSQL

Backend desarrollado con Node.js, Express, TypeScript, Mongoose, Zod y MongoDB Atlas para la gestión de incidencias del campus.

## Requisitos previos
- Node.js instalado en tu computadora.
- Una cuenta o acceso a la base de datos de MongoDB Atlas.
