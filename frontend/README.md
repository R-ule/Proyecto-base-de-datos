# UTM Desk · Frontend (Angular + TypeScript)

## Requisitos
- Node.js 20.19+ (o 22 LTS) y npm

## Ejecutar
```bash
npm install
npm start
```
Abre http://localhost:4200

## Estructura
- `src/app/pages/login/` pantalla de inicio de sesión
- `src/app/layout/` sidebar + barra superior compartidas
- `src/app/pages/inicio/` dashboard del reportante
- `src/app/core/` modelos, datos de ejemplo, íconos
- `src/app/app.routes.ts` rutas (carga diferida)
- `src/styles.scss` tokens de diseño (colores, radios, tipografía)
